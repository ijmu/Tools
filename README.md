## 使用

在 Egern 中导入模块 Raw URL，并按对应 YAML 的 `env_schema` 配置参数；脚本通常由模块自动引用，规则集请确认策略组名称后再启用。使用前请备份配置，并确认 Egern/iOS 版本及第三方服务状态。
