## 使用方式

### 导入模块

1. 在 Egern 中打开模块管理，添加对应模块文件中的 Raw URL，或按文件内容手动创建模块。
2. 根据模块页面中的 `env_schema` 填写参数；每个模块的安装、用途、参数和注意事项以对应 YAML 文件为准。
3. 添加模块声明的脚本 Widget，并在组件设置中选择对应脚本。
4. 首次运行后检查组件输出、刷新时间和网络请求；出现错误时先检查模块参数、脚本 URL、Egern 版本和第三方服务状态。

模块目录：[Egern/Modules](Egern/Modules/)

### 导入脚本

脚本通常由模块通过 `script_url` 自动引用。手动添加脚本时，应使用对应 YAML 中的脚本 URL、脚本名称和超时时间，不要随意替换为来源不明的脚本。

脚本目录：[Egern/Scripts](Egern/Scripts/)

### 使用规则集

规则集应根据自己的代理配置导入，并确认策略组名称与规则中的 `policy` 设置相匹配。规则可能包含直连、代理或其他策略；导入前请检查实际规则内容和自己的网络需求，不要默认认为所有域名都适合直连或代理。

规则目录：[Egern/Rules](Egern/Rules/)

### 参数与隐私

- `env_schema` 中的参数名称必须与模块实际读取的环境变量一致，不建议凭经验改名。
- 需要登录的模块应只在 Egern 本地设置中填写账号信息，不要把账号密码写进 YAML、截图、Issue、PR 或公开订阅。
- 远程脚本和规则会随上游文件变化；需要稳定性时，请先审阅变更并保留可回退版本。
- 第三方服务可能记录请求时间、IP、设备信息或请求参数，具体以其隐私政策为准。
